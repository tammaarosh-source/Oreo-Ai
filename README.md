# Oreo AI 🍪

Assistente AI in italiano che cerca su Google e risponde in pochi secondi.
Funziona sia in **chat** che con la **voce**.

## Funzionalità
- Ricerca su Google
- Risposta vocale e testuale
- Preferisce fonti affidabili (Wikipedia, siti istituzionali, ecc.)
- Interfaccia semplice da terminale

## Come usarlo

### 1. Installa Python
Scarica Python dal sito ufficiale:  
https://www.python.org/downloads/  
(Importante: spunta la casella "Add Python to PATH" durante l'installazione)

### 2. Installa le librerie
Apri il Prompt dei comandi e scrivi:

```bash
python -m pip install SpeechRecognition pyttsx3 googlesearch-python requests beautifulsoup4
